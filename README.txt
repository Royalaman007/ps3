DISTRICT 360 — Standalone Frontend Demo

HOW TO OPEN
1. Extract the DISTRICT_360_Standalone.zip file.
2. Open the DISTRICT_360_Standalone folder.
3. Double-click index.html.
4. It opens in Chrome, Edge, Firefox, or another modern browser.

No Node.js, npm, installation, server, or internet connection is required.

FEATURES
- Overview dashboard with live KPIs and charts
- Public Works project management (add/edit/delete/view)
- Government Programmes management
- Files & Workflow tracking
- District Assets management
- Alerts & Issues / grievance management
- Reports and CSV exports
- Public Portal with published sample projects/programmes and demo grievance submission
- Settings, JSON backup, and reset sample data
- Browser localStorage persistence

IMPORTANT
This is a standalone frontend demonstration. It uses fictional sample data stored in the browser.
It is not connected to official government systems and does not provide secure authentication,
multi-user synchronization, or a live backend. Do not enter sensitive personal information.
